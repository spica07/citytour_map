# 전국 시티투어 지도 (citytour_map) 설계

작성일: 2026-08-31

## 1. 무엇을 만드는가

공공데이터포털이 개방하는 「전국시티투어정보표준데이터」(지자체가 운영하는 시티투어 버스/코스 안내)를 지도에 표시하는 PWA. 워크스페이스의 기존 지도 프로젝트(`museum_map`, `voucher_map`, `observatory_map` 등)와 같은 계열이며, 빌드 도구 없이 정적 파일로 GitHub Pages에 배포한다.

폴더는 `C:\blog_writing\citytour_map`. 새 git 저장소, GitHub Pages 배포를 위해 public으로 올린다. daitmap 포트폴리오에 카드를 추가한다.

## 2. 데이터 소스

공공데이터포털 표준데이터 「전국시티투어정보표준데이터」(`publicDataPk=15025456`). API키·로그인 없이 `columList.json` + `standard.json`으로 전량 다운로드한다(`museum_map/tools/download_data.py`와 동일한 패턴). 이미 `글감/전국시티투어정보/download_citytour_data.py`로 한 번 내려받아 검증했다 — 이를 `tools/download_data.py`로 옮겨 재사용한다.

- 총 298행, 15개 시도, 78개 시군구
- 컬럼: 시도명·시군구명·시티투어코스명·시티투어문의처·시티투어운영시간·시티투어운행방식·시티투어탑승장소명·시티투어코스정보·경유지주변관광정보·시티투어코스부가정보·운행정보·운행시작시각·운행종료시각·배차시간·이용요금·이용요금부가정보·홈페이지주소·관리기관명·관리기관전화번호·데이터기준일자·제공기관코드·제공기관명

### 이 데이터의 근본적인 한계

**주소도 좌표도 없다.** 위치 정보는 `시티투어탑승장소명` 텍스트 하나뿐이고, 실측 결과 다음과 같은 잡음이 있다.

- 여러 장소를 `+`로 이어붙임: `"청주가경시외버스터미널+청주체육관"`, `"(KTX오송역/토일요일)+청주가경시외버스터미널+청주체육관"`
- 장소가 아니라 안내 문구: `"출발희망지(청주시)"`

(시군구, 탑승장소명) 조합 기준 고유값은 120개. 이 120개 각각에 카카오 지오코딩을 시도한다.

**`운행정보` 필드는 정형화할 수 없다.** 운영요일·중단여부·유의사항이 뒤섞인 자유텍스트로 고유값이 130개 이상이다(`"정상운행"`, `"잠정중단"`, `"현재 미운영 중으로 2024년4월1일 이후 재운행 예정임"`, `"매주 화~일(예약상황에 따라 변동 가능)"` 등 형식이 제각각). 자동으로 "운행중/중단" 상태를 판별하려 하지 않는다 — 오분류 위험이 오분류 없음보다 크다. 원문을 그대로 상세에 노출하고, 다있맵 전체 공지("운영시간·요금 등은 참고용, 방문 전 관련 기관을 통해 재확인")로 갈음한다.

- `이용요금` 무료(0/빈값): 298건 중 5건뿐 — 필터로는 두되 큰 효용은 기대하지 않는다
- `홈페이지주소` 빈값: 298건 중 29건 — 없으면 링크를 만들지 않는다
- `시티투어운행방식`: 고정형 247 / 순환형 51

## 3. 지오코딩 설계

`voucher_map/tools/geocode.py`, `observatory_map/tools/geocode.py`와 같은 카카오 로컬 API 패턴을 쓰되, 탑승장소 텍스트가 지저분한 문제에 맞춰 폴백 사다리를 하나 더 둔다.

```
정제: 괄호 "(...)" 안 내용 제거 → "+" 로 분리해 조각 리스트 생성
  1) 각 조각을 순서대로 "{시군구명} {조각}" 키워드 검색 → 첫 성공 채택
  2) 전부 실패하면 "{시도명} {시군구명}청" 키워드 검색 (군청/시청 좌표로 대체, geoApprox=true)
```

- 카카오 키워드 검색(`/v2/local/search/keyword.json`) 하나만 쓴다. 주소 검색은 애초에 주소가 없어 시도하지 않는다.
- 2)의 "○○청" 검색은 실패 사례가 없다고 가정하지 않는다 — 그래도 실패하면 시군구 중심 좌표(별도 조회) + 결정적 지터로 마지막 폴백을 둔다 (voucher_map의 `SEOUL_CENTERS` 패턴을 전국판으로 확장할 필요는 없고, 실패 시점에 그 시군구 이름으로 키워드 검색해 좌표를 구해 캐시한다).
- `kakao_cache.json`으로 재실행 시 이미 조회한 질의는 건너뛴다.
- 마커 데이터에 `geoApprox` 플래그를 남겨, 상세 패널에 "탑승 위치는 근사치입니다" 안내를 붙인다(2)와 폴백 케이스만 해당).

## 4. 마커와 상세 정보

마커 단위는 **(시군구, 탑승장소명) 조합 = 120개.** 같은 탑승장소에서 출발하는 코스가 여럿이면 한 마커에 묶는다.

마커 클릭 시 패널에 표시:
- 탑승장소명, 시도/시군구
- 그 지점에서 출발하는 코스 목록, 코스별로: 코스명 · 운행방식(고정형/순환형) · 운영시간 · 운행정보(원문) · 운행시작~종료시각 · 배차시간 · 이용요금(+부가정보) · 코스정보(경유지) · 경유지주변관광정보 · 홈페이지 링크(있을 때만) · 문의처

## 5. 필터 · UI

`museum_map`의 검색창 + 시군구 select + 칩 필터 구조를 따른다.

- 검색: 코스명 · 시군구명
- 시도 select
- 운행방식 칩: 고정형 / 순환형
- 빠른필터 칩: 무료로 이용 (5건 한정, 참고용으로 유지)

그 밖 워크스페이스 공통 규칙:
- 마커 기반 지도이므로 `markDokdo()` + `.dokdo-label`로 독도 직접 표시 (위도 37.2429 / 경도 131.8664, 경상북도 울릉군 울릉읍 독도리)
- 국기 이모지 포함 이모지 전면 미사용, 아이콘은 인라인 SVG
- "내 주변" 기능은 10개 지도가 공유하는 `assets/js/geo.js`를 그대로 복사해 11번째로 추가한다. `unitLabel`은 받침으로 끝나야 하므로("~이 없어요" 조립) `"탑승장"`을 쓴다(정류장·탑승장 모두 'ㅇ' 받침). 목록이 100곳 미만이므로 "가까운 N곳"의 `limit`도 줄인다.
- `report.html`은 정제 통계 확인용으로만 두고 UI에서는 기본 숨김

## 7. daitmap 반영

`daitmap/index.html` 그리드에 카드 한 장 추가:
- 제목: "전국 시티투어 지도", 설명: 지자체 시티투어 버스·코스 요금·시간 한눈에 (문구는 구현 시 최종 확정)
- plaque 색상은 기존 17장과 겹치지 않는 새 색
- 인라인 SVG 아이콘(버스/투어 컨셉, 기존 카드들과 톤 일치)
- 헤더 설명 문구와 footer 안내 목록에도 새 지도 추가를 반영 (출처 문구: 이 지도는 공공데이터포털 표준데이터 출처라 특별한 예외 문구는 필요 없음 — 물놀이장/이용권/천문대처럼 출처가 다른 케이스가 아님)

## 8. 검증

- `download_data.py`가 받은 총 건수(298)와 화면에서 다시 확인한 수치가 일치하는지
- 지오코딩 결과 중 `geoApprox` 비율이 지나치게 높지 않은지 (체감상 절반 이상이면 정제 규칙 재검토)
- 마커를 실제로 띄워 시도 필터·검색·상세 패널이 정상 동작하는지
- 독도가 표시되는지
- daitmap에서 새 카드가 열리고 GitHub Pages 배포 URL이 살아있는지
