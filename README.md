# 전국 시티투어 지도 (citytour_map)

지자체가 운영하는 시티투어 버스·코스 289건(110개 탑승장소 마커)을 지도에서 찾아보는 PWA. 빌드 도구 없이 정적 파일로 동작한다.

- Leaflet + OpenStreetMap 타일
- 시도 → 시군구 필터, 운행방식(고정형/순환형) 필터, 무료 코스 빠른필터
- 코스 이름·시군구 검색
- 오프라인 지원(서비스워커), 홈 화면 설치

## 데이터

출처는 공공데이터포털 「전국시티투어정보표준데이터」(`publicDataPk=15025456`, 원본 298행).
원본에 주소·좌표가 없어(탑승장소명 텍스트뿐) 카카오 로컬 API로 지오코딩한다.
탑승장소명이 여러 곳을 `+`로 합치거나 모호한 문구인 경우가 많아, 지오코딩 사다리를 3단으로 둔다.

1. `"{시군구명} {조각}"` 키워드 검색 (조각 = 탑승장소명을 `+`로 나눈 각 항목)
2. 1이 실패하면 `"{시도명} {조각}"`으로 재시도 (시군구명 자체가 `"없음"`이거나
   `"연수구+중우"`처럼 손상된 경우, 시군구명을 빼고 검색)
3. 2도 실패하면 `"{시도명} {시군구명}청"`(군청/시청) 좌표로 대체

2·3단계로 얻은 좌표는 `geoApprox: true`로 표시한다.

(시군구명, 탑승장소명) 조합 자체가 지오코딩 불가능한 경우(시군구명이 `"없음"`이거나
`"중우"`처럼 다른 값과 손상되어 있어 어떤 검색으로도 결과가 나오지 않는 경우)는
지도에서 아예 제외한다 — 4개 조합 / 원본 11행. 이 값은 `report.html`의 `skippedCount`
통계로 확인할 수 있다(메인 UI에는 연결하지 않음, 워크스페이스 공통 규칙).

지오코딩에는 성공하지만(117개 조합) 좌표와 탑승장소명이 완전히 같은 마커는
`build_data.py`가 하나로 병합한다(같은 실제 장소가 손상된 시군구명 탓에 여러 조합으로
쪼개져 있는 경우 — 예: 인천종합관광안내소가 "연수구+중구"/"연수구+강화군" 등으로
따로 잡힘, 또는 다른 지자체 코스가 타지역 명소를 탑승장소로 쓰는 경우 — 예: 경기도
안산시 코스가 "광화문역"에서 출발). 그래서 최종 지도 마커 수(110)는 지오코딩 성공
수(117)보다 적다. 병합된 마커의 시도/시군구는 그룹 안에서 `geoApprox: false`인
쪽(그 물리적 위치를 직접 검색해 정확히 맞힌 쪽)을 우선 채택한다.

### 서울시티투어버스 — 수동 추가

표준데이터셋 자체에 서울특별시 항목이 없다(2026-09-01 기준 298행 중 시도명이
`서울특별시`인 행 0건 — 표준데이터 등록은 지자체 재량이라 서울시/운영사가 참여하지
않은 것으로 보인다). 그래서 `tools/manual_rows.csv`에 서울시티투어버스 공식
사이트(seoulcitybus.com)에서 확인한 정기 운행 코스 2개(도심고궁남산코스 주간,
야간 한강·남산 코스)를 원본 CSV와 같은 컬럼 구조로 직접 채워 넣었다. 계절 한정
익스클루시브 상품(썸머 인 서울 등)은 다른 지자체 데이터의 성격(상시 운행 노선)과
맞지 않아 넣지 않았다.

`manual_rows.csv`는 `download_data.py`가 건드리지 않는 별도 파일이라 CSV를
재다운로드해도 사라지지 않는다. `geocode.py`·`build_data.py`가 `citytour_raw.csv`와
이 파일을 합쳐서 처리한다. 서울시티투어버스 정보가 갱신되면(요금·시간 변경 등)
이 파일을 직접 고치고 `geocode.py`→`build_data.py`를 다시 돌리면 된다.

## 갱신 절차

`tools/geocode.py`를 돌리려면 `.env`에 `KAKAO_REST_KEY`가 있어야 한다(`.env.example` 참고).
또 `requests`(geocode.py용)와 `Pillow`(`tools/make_icons.py`용) 패키지가 필요하다:
`py -m pip install requests Pillow`

```bash
py tools/download_data.py   # CSV 재다운로드 → tools/citytour_raw.csv
py tools/geocode.py         # 카카오 지오코딩 (캐시됨) → tools/geocoded.json
py tools/build_data.py      # 정제 → assets/js/data.js
```

`sw.js`의 `CACHE` 버전 숫자를 올려야 이용자에게 새 데이터가 내려간다.

## 규칙

- 독도를 항상 직접 그린다(위도 37.2429 / 경도 131.8664, 경상북도 울릉군 울릉읍 독도리).
- 국기 이모지를 포함해 UI에 이모지를 쓰지 않는다.
- 파이썬은 `python`이 아니라 `py`로 실행한다.
- `운행정보` 필드는 자유텍스트라 운행 중단 여부를 자동 판정하지 않고 원문을 그대로 보여준다.
